## Design Guidelines for Canva AI

### Color Palette
- Primary: Deep Blue (#1E40AF)
- Secondary: Teal (#0D9488) 
- Accent: Electric Blue (#3B82F6)
- Background: Clean White/Light Gray
- Text: Dark Gray (#374151)

### Visual Elements
- Clean, modern design with plenty of white space
- Icons: Use tech-focused iconography (gears, networks, clouds, brains)
- Charts: Simple, clean data visualizations
- Arrows: Show flow and connections between components
- Boxes: Clean containers for content organization

### Typography
- Headers: Bold, sans-serif font
- Body: Clean, readable sans-serif
- Code snippets: Monospace font for technical examples
- Emphasis: Use color and weight, not excessive styling

### Image Suggestions
- Network/connection graphics for architecture diagrams
- Abstract brain/AI imagery for intelligence concepts
- Clean geometric shapes for process flows
- Minimal illustrations over photographs
- Consistent icon style throughout
